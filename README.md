# AI Community Resource Matching Platform

## Team CodeNova
Mangayarkarasi College of Engineering

### Problem Statement
S15 - AI Community Resource Matching Platform

## About the Project

Our platform connects community requests with available resources based on:

- Request category
- Priority
- Location
- Quantity
- Resource availability
- Distance between request and resource

The system supports request creation, resource registration, intelligent matching,
resource allocation and fulfillment tracking.

## Features

- Community Help Request
- Resource Registration
- Priority Calculation
- Intelligent Resource Matching
- Match Score
- Live Location Capture
- Nearest Resource Identification
- Resource Allocation
- Dashboard with Database Counts
- Fulfillment Tracking Structure
